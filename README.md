# SBS Mumbai Holiday List

A clean, responsive web application designed to help users view and track the holiday schedule for the SBS Mumbai office. The application provides an easy way to check upcoming holidays, browse the holiday list, and access the local map.

## ✨ Features

- **Home Page** — A welcoming landing page with an overview of the application.
- **Holiday List** — View holiday dates, days, and holiday names in an organized table.
- **Upcoming Holiday Highlight** — Quickly identify the next upcoming holiday.
- **Local Map** — Access the Mumbai local map through a dedicated page.
- **Responsive Design** — Optimized for desktop, tablet, and mobile screens.
- **Modern UI** — A clean interface with consistent colors, typography, cards, and interactive elements.

## 🚀 Getting Started

### Prerequisites

Make sure the following tools are installed:

- [Node.js](https://nodejs.org/)
- [Angular CLI](https://angular.dev/tools/cli)
- npm

### Installation

1. Clone the repository:

   ```bash
   git clone (https://github.com/wasimk1/SBSMumbaiHolidayList.git)
   ```

2. Navigate to the project directory:

   ```bash
   cd <your-project-folder>
   ```

3. Install the dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   ng serve
   ```

5. Open your browser and visit:

   `http://localhost:4200/`
